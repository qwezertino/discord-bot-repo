# Discord Bot Panel

Общайся с владельцем на русском. Не делай commit/push без прямого запроса.

## Текущее состояние

Это самостоятельная копия `../perimeter_fivem/tools/discord_bot`, а не часть FiveM
или KCD:MP. Приложение поддерживает несколько профилей ботов с отдельными клиентами
и изоляцией данных по bot_id. Профили игровых проектов и игровые интеграции
ещё не реализованы. Поддерживаются Discord OAuth, владелец и права на ботов;
локальный режим остаётся доступен через PANEL_AUTH_MODE=local.
`NEXT_SESSION_PROMPT.md` содержит исходные требования первого этапа.

Стек: Python 3.12+, FastAPI, discord.py, SQLite, HTML/CSS/JavaScript.
Запуск: `./run.sh` или `run.bat`; вход: `run.py`; приложение: `app/web.py`;
Discord: `app/discord_service.py`; настройки: `app/config.py`; БД: `app/database.py`.
Интерфейс — украинский/английский; общий словарь: `app/static/translations.json`,
переключение: `app/static/i18n.js`, ошибки API: `app/i18n.py`.
Вход и права: `app/auth.py`, `app/auth_routes.py`; защита API: `app/web.py`.
Не ослабляй проверки авторизации и не включай local как автоматический fallback.

## Работа с проектом

- Сначала прочитай существующие сервисы и тесты, сохраняй рабочие функции.
- Обычные инструменты панели не должны зависеть от файлов и БД соседних игр.
- Не изменяй соседние репозитории для обхода архитектурных ограничений.
- Токены, реальные `.env`, SQLite, вложения, логи и окружения не переносились.
  Не копируй их автоматически из соседних проектов и не выводи секреты в ответах.
- Перенос схемы делай миграциями, без удаления пользовательских данных.
- Каждый Discord ID храни строкой, в том числе в JavaScript и JSON.
- Не отправляй сообщения, не выдавай роли и не меняй Discord-серверы без явного
  задания владельца на такие действия. Проверки выполняй с mock-клиентами.
- Панель по умолчанию слушает localhost. Административную панель нельзя
  автоматически публиковать через публичный туннель игрового OAuth.
- Проверки: `.venv/bin/python -m pytest`, `node --check app/static/app.js`,
  `sh -n run.sh`, `git diff --check`.
- Различай проверки с заглушками и поведение реально подключённого Discord-бота.

## Соседние проекты

У KCD:MP уже работает собственный сервис привязки Discord. Его данные и настройки
хранятся в PostgreSQL. Существующие привязки и игровую авторизацию не переносить
в SQLite панели и не выключать автоматически. Подключение — отдельный адаптер.
На запуск этой панели не распространяется разрешение перезапускать другие проекты.
